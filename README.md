# COMP9320 — Computer Vision

## Overview

This repository contains assignments and practical implementations developed as part of the PhD-level Computer Vision course (COMP9320) at Birzeit University.

The assignments are completed and maintained as educational references for future study, revision, and reinforcement of fundamental and advanced Computer Vision concepts.

Each assignment aims to connect theoretical foundations and mathematical concepts with practical implementations, experiments, visualizations, and critical interpretation of results.

## Assignments

| Assignment | Topics | Status |
|------------|--------|--------|
| [Assignment 1](Assignments/Assign_1/) | Image representation, Canny edge detection, Gaussian filtering, noise removal, and Laplacian pyramid blending | Completed |

Additional assignments will be documented here as they are completed.

## Repository Organization

- `Assignments/` — Individual assignment folders containing notebooks, instructions, datasets, and related outputs.
- `requirements.txt` — Python dependencies used for the implementations.

Each assignment folder may include its own README with task-specific descriptions, implementation details, and instructions.

## Learning and Revision

This repository serves as a structured learning reference rather than merely a collection of submitted solutions.

When revisiting an assignment, the recommended approach is to review the underlying concepts, mathematical foundations, implementation decisions, experimental results, and observations together.
